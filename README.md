# DipTrace Field Cleaner

Автономная HTML-утилита для приведения пользовательских полей (`AddFields`) в XML-библиотеках DipTrace (`.elixml`, `.libxml`) к заданному списку.

**Онлайн:** https://wadi-li.github.io/diptrace-field-cleaner/
**Офлайн:** скачайте `DipTrace_Field_Cleaner.html` и откройте в браузере — сервер и интернет не нужны, файл обрабатывается локально.

## Возможности

- Отдельные списки оставляемых полей для компонентов (Part) и корпусов (Pattern) или один общий список.
- Удаление всех полей, которых нет в списке; предупреждение, если удаляемые поля заполнены.
- «Добавить недостающее поле, если отсутствует» — пустые поля добавляются в компоненты, в корпуса с полями и (по выбору) в корпуса без полей. Тип Text/Link берётся из этого же поля в файле; для новых имён — Link, если имя оканчивается на `_url`.
- «Сортировка полей, как в списке»; поля вне списка уходят в конец без изменения порядка.
- Сохранение и загрузка настроек (списки и все параметры) в JSON-файл; пример — `diptrace_fields_settings.example.json`. Файл можно перетащить в поле загрузки.
- Отчёт об удалённых и добавленных полях в CSV (разделитель `;`, UTF-8 с BOM).
- Светлая тема по умолчанию и тёмная тема.

## Порядок работы

1. В редакторе компонентов DipTrace сохраните библиотеку в XML (Файл → Экспорт → XML). Бинарный `.eli` утилита не изменяет.
2. Загрузите `.elixml`, проверьте списки полей и таблицы «Имена полей» / «По объектам».
3. Скачайте результат (`*_clean.elixml`) и импортируйте его в DipTrace (Файл → Импорт → XML), сначала в новую пустую библиотеку.

## Как сохраняется файл

- XML не сериализуется заново: меняются только блоки `<AddFields>`, остальной текст, BOM и переводы строк сохраняются байт в байт. Если изменений нет, результат идентичен исходному файлу.
- Новые поля и блоки оформляются так же, как в файлах DipTrace; блок полей корпуса вставляется перед `DefPad`/`Pads`/`Shapes`.
- Перед сохранением проверяются корректность XML и итоговое число полей.

## Ограничения

Проверено на реальной библиотеке (161 компонент, 53 корпуса): структура результата совпадает с исходной — новых последовательностей тегов и атрибутов нет. Импорт результата в DipTrace в рамках публикации не проверялся; используйте копию библиотеки.
